# Python Web Security & File Exposure Scanner

A lightweight Python-based security auditing script designed to check web applications for missing security headers and publicly exposed sensitive paths/files.

## Features
- **HTTP Header Analysis:** Checks for missing critical security headers.
- **Sensitive Path Enumeration:** Probes target URLs for common sensitive files (e.g., .env, .git/config).

## Usage
python3 scanner.py http://localhost:8501
